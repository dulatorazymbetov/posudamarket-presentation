Как работает система
Четыре роли с разграниченным доступом и системой invite-ссылок

🛡 Администратор

  • Управляет поставщиками и оптовиками
  • Назначает default-поставщика для новых оптовиков
  • Блокирует поставщиков и управляет подписками
  • Видит всю аналитику платформы и платежи
  • Выдаёт ручной доступ, промокоды

🏭 Поставщик

  • Управляет своим каталогом товаров, категориями, остатками
  • Загружает фото товаров
  • Получает уникальную invite-ссылку для привлечения оптовиков
  • Видит список оптовиков, подключившихся по ссылке
  • Видит входящие заказы от оптовиков

📦 Оптовик

  • После регистрации — бесплатно видит 1 default-поставщика
  • Добавляет поставщиков навсегда по invite-ссылкам (бесплатно)
  • По подписке — открывает всех поставщиков платформы
  • Оформляет заказы коробками у доступных поставщиков
  • Видит статус подписки, тарифы, историю платежей

🛍 Клиент

  • Заходит на сайт магазина и видит розничный каталог
  • Добавляет товары в корзину, оформляет заказ
  • Видит статус своих заказов в личном кабинете
  • Получает уведомление при подтверждении заказа

RBAC · Роли и доступы

  • admin — полный доступ, управление платформой
  • supplier — только свои товары, остатки, invite, заказы
  • wholesaler — каталог доступных поставщиков, заказы
  • Middleware: role:admin, role:supplier, role:wholesaler
  • Gate: access-supplier — проверка доступа оптовика к поставщику

API · Ключевые эндпоинты

  • POST /auth/register — регистрация с ролью
  • GET /invite/supplier/{code} — публичная страница invite
  • POST /invite/supplier/{code}/attach — прикрепить поставщика
  • GET /my-suppliers — мои поставщики (для оптовика)
  • GET /subscription — статус подписки
  • GET /suppliers — с фильтрацией по доступу

Логика доступа к поставщикам

  • При регистрации → автоматически добавляется default supplier
  • Invite-переход → запись в wholesaler_suppliers (source: invite)
  • Подписка активна → все is_active поставщики доступны
  • Подписка истекает → source=subscription записи игнорируются
  • Новый поставщик → автоматически всем с активной подпиской

Интеграции · Дорожная карта

  • Telegram-бот: уведомления, заказы, остатки
  • Kaspi Pay: приём оплаты за подписку
  • 1С: выгрузка накладных и остатков
  • Push/Email: напоминания об окончании подписки
  • Webhook: уведомления при новом заказе
  • CRM: передача лидов от invite-переходов
