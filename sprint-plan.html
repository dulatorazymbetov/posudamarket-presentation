4 Детали вывода на сервер

🖥
Рекомендуемый сервер: Hetzner CX32 или Beget VPS 4 ядра CPU · 8 ГБ RAM · 80 ГБ SSD · Ubuntu 22.04. Hetzner — ~5 000–7 000 ₸/мес (самый надёжный). Beget — ~15 000–20 000 ₸/мес (казахстанская поддержка). DigitalOcean — ~8 000–10 000 ₸/мес.
⚙️ Пошаговый план деплоя (день 9)
1
Аренда VPS и настройка окружения
Ubuntu 22.04 · PHP 8.2 · MySQL 8 · Nginx · Redis · Supervisor · Certbot (SSL)
~1–2 ч.
2
Регистрация и настройка домена (.kz)
Купить домен posudamarket.kz или pm.kz. Прописать A-запись на IP сервера. Certbot выдаёт SSL автоматически.
~30 мин.
3
Деплой Laravel backend
git clone · composer install · .env (DB, MAIL, APP_KEY) · php artisan migrate --seed · storage:link · queue:work через Supervisor · schedule:run через cron
~2 ч.
4
Деплой Vue frontend
npm run build · скопировать dist/ на сервер · Nginx раздаёт статику · .env.production с URL API
~1 ч.
5
Настройка бэкапов и мониторинга
Ежедневный дамп MySQL → S3/Backblaze. Cron-проверка доступности. UptimeRobot (бесплатный мониторинг).
~1 ч.
6
Смоук-тест на боевом сервере
Регистрация всех ролей · invite-флоу · подписка · добавление товара · склад · заказ · накладная PDF
~2 ч.
